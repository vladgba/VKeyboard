# Additional language layouts

The layouts generated by `tools/generate-language-layouts.py` are independently authored mobile adaptations of conventional national letter arrangements. No external layout files, dictionaries, executable keyboard implementations or fonts are copied.

The public reference index is [Microsoft's published keyboard arrangements](https://learn.microsoft.com/en-us/globalization/windows-keyboard-layouts). Relevant entries: Arabic (101), Hebrew (Standard, 2018), Greek, Turkish Q, Italian, Portuguese, Czech, Hungarian, Swedish, Finnish, Norwegian and Danish. These provide reference letter positions; the mobile function row, navigation, modifier handling and swipe/hold accents are our own design. This is not a claim of full physical-keyboard conformance.

Arabic includes ذ on ض hold/swipe and أ/إ/آ on ا; lam-alef inserts two standard letters rather than a presentation-form glyph. Hebrew includes final letter forms. Latin/Greek accents that normally share physical keys are available through hold/swipe. Swedish and Finnish use their shared letter arrangement with separate speech-language metadata. Turkish dotted/dotless I uses Turkish casing.

The library is off by default. Enable Expanded language layouts in Settings, then add desired layouts from Built-in layouts. Disabling the library excludes those entries from normal layout selection and returns the keyboard to an available basic layout without deleting custom files.
